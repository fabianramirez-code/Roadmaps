# Compilación a bytecode y ejecución — ciclo fuente, .class, carga, interpretación y JIT

El **ciclo de ejecución de Java** comienza con la compilación a **bytecode**, donde el compilador `javac` transforma el código fuente (`.java`) en un archivo intermedio independiente de la plataforma (`.class`).  Este **bytecode** es un formato binario compacto diseñado para la Máquina Virtual de Java (JVM), permitiendo la portabilidad "escribe una vez, ejecuta en cualquier lugar".

Durante la ejecución, el Cargador de Clases (`Class Loader`) carga el archivo `.class` en la memoria de la JVM, verificando su validez y seguridad.  El Motor de Ejecución (`Execution Engine`) procesa este bytecode mediante un modelo híbrido que combina la interpretación inmediata (para arrancar rápido) y la compilación **Just-In-Time (JIT)**.

El compilador JIT optimiza el rendimiento identificando las secciones de código más ejecutadas (hot spots) y las compila a código máquina nativo de la CPU específica.  Este código nativo se almacena en caché para reutilizarse en llamadas futuras, superando la velocidad de la interpretación pura mientras mantiene la portabilidad inicial del bytecode.

| Fase | Componente/Proceso | Acción Principal | Resultado |
| :--- | :--- | :--- | :--- |
| **1. Compilación** | `javac`| Traduce código fuente a instrucciones de la JVM. |  Archivo .class (Bytecode).|              
| **2. Carga** | `Class Loader` | Encuentra y carga la representación binaria en memoria. |  Clases disponibles en la JVM.|
| **3. Ejecución** | `Execution Engine` | Interpreta bytecode o usa el compilador JIT.|  Código nativo optimizado.|
| **4. Optimización** | Compilador **JIT** | Convierte código frecuente en código máquina nativo.|  Máximo rendimiento en tiempo de ejecución.|
