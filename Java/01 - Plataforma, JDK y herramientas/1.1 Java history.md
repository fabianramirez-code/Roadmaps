# Historia de Java (Sun, Oracle, OpenJDK) — hitos desde JDK 1.0 hasta hoy

**Long-Term Support (Soporte a Largo Plazo)**

RELEASE with LTS: 8, 11, 17, 21, 25, 29

Java fue creado en 1991 por James Gosling y su equipo en SUN MICROSYSTEMS bajo el nombre de **OAK** con el objetivo inicial de programar dispositivos embebidos electrodomesticos inteligentes. 

Se renombro a **JAVA** y se lanzo al publico en 1995 con el lema **"Escribe una vez, ejecuta en todas partes"** gracias a la maquina virtual de Java **(JVM)**.

Sun Microsystems lanzo le proyecto OpenJDK en 2006 bajo licencia GPL. En 2010 Oracle adquirio Sun Microsystems y Oracle introdujo un ciclo de lanzamiento de 6 meses iniciando con Java 9 en 2017 y modelos de licencia comercial para el JDK.

## Licencias — Resumen práctico
Si usas cualquier distribución **OpenJDK** (Temurin, Corretto, Zulu, Liberica, Microsoft Build, etc.) → solo hay una licencia: GPLv2+CPE, gratis para todo.

Si usas Oracle JDK → dependes de la versión y la fecha:
- JDK 25 → NFTC, gratis hasta sep 2028.
- JDK 21 → ya pasó a OTN desde el CPU de octubre 2026; producción requiere suscripción.
- JDK 17 / 11 / 8 → OTN desde hace tiempo; producción requiere suscripción.

Es decir, en la práctica hay dos mundos: el mundo **OpenJDK** (una sola licencia, GPL) y el mundo **Oracle JDK** (tres licencias que se encadenan temporalmente: **NFTC → OTN → suscripción de pago).**

### En la actualidad (noviembre 2026) existen 4 licencias activas más una histórica:

| **Licencia** | **Aplica a**| **¿Gratis en producción?**| **Restricción clave** |
|---|---|---|---|
| **GPLv2 + CPE** | OpenJDK (y todos sus derivados: Temurin, Corretto, Zulu, Microsoft Build, etc.) | **Sí**, para siempre | Solo exige que modificaciones al propio JDK se publiquen bajo GPL |
| **NFTC** (No-Fee Terms & Conditions) | Oracle JDK 25 (hasta sep 2028); fue para JDK 21 hasta sep 2026 | **Sí**, pero con ventana temporal | Deja de aplicarse 1 año después del siguiente LTS; pasa a OTN |
| **OTN** (Oracle Technology Network) | Oracle JDK 8 (≥8u211), 11, 17 (≥17.0.13), 21 (desde oct 2026) | **No** — solo personal, dev, test, prototipado y demo | Uso en producción requiere la suscripción de pago |
| **Java SE Universal Subscription** | Oracle JDK (cualquier versión bajo OTN) | Es la licencia **de pago** | $15 → $5.25 por empleado/mes según banda; cubre a *todos* los empleados de la empresa |
| ~~BCL~~ (Binary Code License) | Java 8 hasta 8u202 (2019) | Sí, pero **obsoleta** | Ya no recibe parches; solo de interés histórico |
