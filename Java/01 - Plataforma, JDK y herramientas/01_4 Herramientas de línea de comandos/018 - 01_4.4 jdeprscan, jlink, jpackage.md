# jdeprscan, jlink, jpackage

## jdeprscan — detectar usos de API obsoletas

Una Application Programming Interface (API) es el conjunto de clases y métodos que ofrece una biblioteca. `jdeprscan` busca referencias a API **deprecadas** en código compilado: métodos aún presentes pero desaconsejados, algunos marcados para eliminación ([manual de jdeprscan](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jdeprscan.html)). Acepta un archivo `.class`, un directorio de clases o un Java Archive (JAR), archivo que agrupa clases y recursos.

| Opción | Función |
|---|---|
| `--release 25` | Consulta las deprecaciones de Java 25; usa una versión admitida por tu `jdeprscan --help`. |
| `--for-removal` | Limita el resultado a API marcadas para eliminación. |
| `--list` | Enumera las API deprecadas de la versión elegida **sin analizar archivos**. |
| `-v` | Muestra información adicional del análisis; puede producir mucha salida. |

Reutiliza la idea de `Prueba.java` de la nota 017 (`java.sql.Connection` y `java.util.List`) y añade un método deprecado **que no se ejecuta**. Crea este único archivo dentro de `Ejemplos_018`:

```java
import java.sql.Connection;
import java.util.List;

public class Prueba {
    public static List<String> nombres(Connection conexion) {
        return List.of();
    }

    public static void obsoleto(Thread hilo) {
        hilo.stop();
    }

    public static void main(String[] args) {
        System.out.println("Hola Java");
    }
}
```

`Thread.stop()` está marcado para eliminación: el compilador avisa y `jdeprscan` detecta la referencia aunque nunca se llame al método. No ejecutes `obsoleto`: en versiones actuales `stop()` lanza una excepción.

```bash
javac -d input Prueba.java                       # Crea input\Prueba.class; emite una advertencia
jdeprscan --release 25 --for-removal input       # Detecta Thread.stop() en el directorio
jdeprscan --release 25 -v input\Prueba.class    # Analiza una clase con más detalle
jdeprscan --release 25 --list                    # Lista API deprecadas, sin ruta de entrada
```

## jlink — entorno de ejecución a medida

Disponible desde Java 9 ([JDK Enhancement Proposal (JEP) 282](https://openjdk.org/jeps/282)); una JEP es una propuesta numerada de mejora del Java Development Kit (JDK). `jlink` **reúne módulos y dependencias en una imagen ejecutable de Java, sin incluir todo el JDK** ([manual de jlink](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jlink.html)). Normalmente utiliza los módulos del directorio `jmods` del JDK; [JEP 493](https://openjdk.org/jeps/493) habilitó en Java 24 el enlazado desde una imagen de ejecución sin archivos Java Module (JMOD), con las capacidades necesarias. No presupongas que cualquier entorno de ejecución antiguo sirve para enlazar.

| Opción | Función |
|---|---|
| `--add-modules java.base,java.sql` | Módulos raíz; `jlink` incorpora además sus dependencias. |
| `--output runtime` | Directorio **nuevo** donde se crea la imagen. |
| `--strip-debug` | Omite información de depuración. |
| `--compress zip-6` | Comprime recursos (sintaxis de Java 25; comprueba `jlink --help` en otras versiones). |
| `--no-header-files` / `--no-man-pages` | Omite cabeceras nativas / páginas de manual. |

La nota 017 usa `jdeps --list-deps` para obtener los módulos requeridos; aquí muestra `java.base` y `java.sql`. El comando `--list-modules` pertenece a **`java`**, no a `jlink`: permite comprobar los módulos de la imagen, incluidos los transitivos.

```bash
jdeps --list-deps input
jlink --add-modules java.base,java.sql --output runtime --strip-debug --compress zip-6 --no-header-files --no-man-pages # Crea el directorio runtime 
.\runtime\bin\java --list-modules # Lista los moodulos
(Get-ChildItem runtime -Recurse -File | Measure-Object -Property Length -Sum).Sum / 1MB # Tamaño de archivos en MiB
```

## jpackage — aplicación e instalador nativo

Incubado en Java 14 y definitivo en Java 16 ([JEP 392](https://openjdk.org/jeps/392)), `jpackage` distribuye la aplicación **con** un entorno de ejecución: **puede crear una imagen de aplicación (`app-image`) o un instalador nativo** ([manual de jpackage](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jpackage.html)). `jlink` solo crea el entorno; `jpackage` lo empaqueta con la aplicación y, si eliges `exe` o `msi` en Windows, genera un instalador. Esos instaladores requieren [WiX Toolset](https://docs.oracle.com/en/java/javase/25/jpackage/packaging-overview.html); `app-image` no lo requiere.

| Opción | Función |
|---|---|
| `--input input` | Directorio con el JAR y los demás archivos de la aplicación. |
| `--main-jar Prueba.jar` | JAR principal, ruta relativa a `--input`. |
| `--main-class Prueba` | Clase principal del JAR. |
| `--name PruebaApp` | Nombre de la aplicación y del lanzador. |
| `--type app-image` | Crea una carpeta ejecutable; `exe` / `msi` crean instaladores en Windows con WiX Toolset. |
| `--runtime-image runtime` | Reutiliza la imagen de `jlink`; si se omite, `jpackage` invoca `jlink`. |
| `--dest salida` | Directorio de destino. |

Con los archivos anteriores, empaqueta y prueba la imagen. `--win-console` hace visible la salida de esta aplicación de consola en Windows.

```bash
jar --create --file input\Prueba.jar --main-class Prueba -C input Prueba.class
jdeprscan --release 25 --for-removal input\Prueba.jar # También acepta JAR

# usa app-image (nativo)
jpackage --type app-image --input input --main-jar Prueba.jar --main-class Prueba --name PruebaApp --runtime-image runtime --dest salida --win-console # Crea el .exe 

# usa WiX (hay de descargarlo) solo cambia --type msi/exe para la salida
jpackage --type msi --input input --main-jar Prueba.jar --main-class Prueba --name PruebaApp --runtime-image runtime --dest salida --win-console # Crea el .msi

.\salida\PruebaApp\PruebaApp.exe # Hola Java
```

# Comandos para Linux/macOS

Solo cambian los separadores de ruta, el lanzador y la opción de consola exclusiva de Windows. Para `jpackage`, omite `--win-console`:

```bash
jdeprscan --release 25 -v input/Prueba.class
jar --create --file input/Prueba.jar --main-class Prueba -C input Prueba.class
jdeprscan --release 25 --for-removal input/Prueba.jar
jpackage --type app-image --input input --main-jar Prueba.jar --main-class Prueba --name PruebaApp --runtime-image runtime --dest salida
./salida/PruebaApp/bin/PruebaApp # Linux: Hola Java
./salida/PruebaApp.app/Contents/MacOS/PruebaApp # macOS: Hola Java
./runtime/bin/java --list-modules
du -sh runtime # Espacio ocupado por la imagen
```
