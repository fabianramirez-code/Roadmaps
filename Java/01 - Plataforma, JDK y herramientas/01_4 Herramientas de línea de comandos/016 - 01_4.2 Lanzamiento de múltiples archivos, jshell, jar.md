# Lanzamiento de múltiples archivos, jshell, jar

## Lanzamiento de múltiples archivos fuente

Java 22+ (JEP 458): extiende `java Archivo.java` para programas de varios `.java`. Compila en memoria, sin generar `.class`. Cuando el archivo lanzado usa otra clase, `java` la busca como `.java` en la misma carpeta (respetando los paquetes).

`Principal.java`:

```java
public class Principal {
    public static void main(String[] args) {
        System.out.println(Saludo.de("Java"));
    }
}
```

`Saludo.java`:

```java
public class Saludo {
    static String de(String nombre) { return "Hola " + nombre; }
}
```

```powershell
java --version
java Principal.java          # Java 22+: OK. Java 21 o menor: "cannot find symbol Saludo"
```

- Se lanza solo el archivo con el `main`; los demás se encuentran por nombre de clase.
- En Java 11-21 (JEP 330) solo funciona con un archivo; para varios hay que usar `javac`.

## jshell

**REPL** (Read-Eval-Print Loop), Java 9+ (JEP 222): ejecuta código línea a línea, sin clase ni `main`. Sirve para probar APIs rápido.

```powershell
jshell
```

```
jshell> int x = 5
jshell> x * 2                        // una expresión crea una variable: $2 == 10
jshell> List.of(1, 2, 3)             // java.util ya está importado por defecto
jshell> /vars                        // variables definidas
jshell> /list                        // todo lo que has escrito
jshell> /exit
```

| Comando | Qué hace |
|---|---|
| `/vars` | Lista variables |
| `/methods` | Lista métodos definidos |
| `/imports` | Imports activos |
| `/list` | Historial de snippets |
| `/help` | Ayuda |
| `/exit` | Sale |

## jar

**JAR**: archivo ZIP con `.class`, recursos y `META-INF/MANIFEST.MF`. Es la unidad de distribución de código Java.

```powershell
javac -d out Principal.java Saludo.java
jar --create --file app.jar --main-class Principal -C out .
java -jar app.jar                      # imprime: Hola Java
```

| Comando | Qué hace |
|---|---|
| `jar --create --file app.jar -C out .` | Crea el JAR con el contenido de `out` (`-C` entra a la carpeta, para que las rutas dentro del JAR no lleven `out\`) |
| `--main-class Principal` | Escribe `Main-Class: Principal` en el manifest; permite `java -jar` |
| `jar --list --file app.jar` | Lista el contenido |
| `jar --extract --file app.jar` | Extrae en la carpeta actual |

Atajos equivalentes: `jar cfe app.jar Principal -C out .`, `jar tf app.jar`, `jar xf app.jar`.

Ver el manifest:

```powershell
mkdir x; cd x
jar --extract --file ..\app.jar
type META-INF\MANIFEST.MF              # Main-Class: Principal
```

> Con `java -jar` se ignora `-cp`: las dependencias deben declararse con `Class-Path` en el manifest (tema 5.2).

# Comandos para Linux/macOS

Cambian solo las rutas y el comando para ver archivos.

```bash
mkdir x && cd x
jar --extract --file ../app.jar
cat META-INF/MANIFEST.MF
```
