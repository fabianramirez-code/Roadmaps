# Lanzamiento de múltiples archivos, jshell, jar

# Lanzamiento de múltiples archivos fuente

Desde Java 22, [JDK Enhancement Proposal (JEP) 458](https://openjdk.org/jeps/458) permite lanzar un programa formado por varios archivos `.java` sin generar `.class`: Java compila en memoria el archivo inicial y busca los otros fuentes por nombre en la misma carpeta, respetando los paquetes. Una JEP es una propuesta numerada de mejora del JDK. El lanzamiento de un solo archivo de Java 11–21 se explica en la nota 015; en esas versiones, para varios fuentes hay que usar `javac`.

Crea `Principal.java` y `Saludo.java`:

```java
// Principal.java
public class Principal {
    public static void main(String[] args) {
        System.out.println(Saludo.de("Java"));
    }
}
```

```java
// Saludo.java
public class Saludo {
    static String de(String nombre) { return "Hola " + nombre; }
}
```

```bash
java Principal.java # Hola Java (Java 22+)
```

Solo se lanza el archivo con `main`; los demás se encuentran por nombre de clase.

## jshell

Desde Java 9, [JEP 222](https://openjdk.org/jeps/222) incluye `jshell`, un Read-Eval-Print Loop (REPL): lee una instrucción, la evalúa y muestra el resultado, sin clase ni `main`. Sirve para probar código rápidamente ([manual de jshell](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jshell.html)).

```bash
jshell
```

En la sesión, escribe lo siguiente (el prefijo `jshell>` es el indicador, no parte de la entrada):

```text
jshell> int x = 5
jshell> x * 2
jshell> List.of(1, 2, 3)
jshell> /vars
jshell> /exit
```

Las expresiones muestran su valor y pueden crear variables temporales; `java.util` está importado por defecto. `/vars` muestra las variables definidas y `/exit` cierra la sesión. Otros comandos útiles: `/methods` (métodos), `/imports` (importaciones activas), `/list` (fragmentos introducidos) y `/help` (ayuda).

## jar

Java Archive (JAR) es un archivo comprimido ZIP que agrupa clases `.class`, recursos y un manifiesto `META-INF/MANIFEST.MF` para distribuir código. La herramienta `jar` lo crea, lista o extrae ([manual de jar](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jar.html)).

| Opción | Función |
|---|---|
| `-C out .` | Incluye el contenido de `out` sin anteponer `out/` a las entradas. |
| `--main-class Principal` | Escribe `Main-Class: Principal` en el manifiesto para permitir la ejecución. |

Compila los dos fuentes y empaqueta la clase principal:

```bash
javac -d out Principal.java Saludo.java
jar --create --file app.jar --main-class Principal -C out .
java -jar app.jar # Hola Java
jar --list --file app.jar # Lista los archivos del .jar, incluyendo donde esta el MANIFEST.MF
```

Formas abreviadas equivalentes para crear, listar y extraer, respectivamente: `jar cfe app.jar Principal -C out .`, `jar tf app.jar`, `jar xf app.jar`. 

> Para inspeccionar el manifiesto sin dispersar los archivos extraídos, crea tú mismo la carpeta `extraido`:

```bash
mkdir extraido
cd extraido
jar --extract --file ..\app.jar
Get-Content META-INF\MANIFEST.MF
cat MANIFEST.MF # Lo podemos leer con cat
```

Al ejecutar un JAR, `java -jar` ignora `-cp`; si hay dependencias externas, el atributo `Class-Path` del manifiesto debe indicar sus rutas relativas al JAR (véase también la nota 015).

# Comandos para Linux/macOS

Las rutas usan `/` en lugar de `\` (`../app.jar` y `META-INF/MANIFEST.MF`); para mostrar el manifiesto usa `cat` en vez de `Get-Content`. Los demás comandos Java no cambian.
