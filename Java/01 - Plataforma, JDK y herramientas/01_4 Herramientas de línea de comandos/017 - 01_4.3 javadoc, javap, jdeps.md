# javadoc, javap, jdeps

# javadoc — generar documentación, snippets (Java 18+, JEP 413), comentarios Markdown (Java 23+, JEP 467)

Genera páginas HyperText Markup Language (HTML) a partir de comentarios de documentación. Crea `Prueba.java` con este contenido; `@param` describe el parámetro y `@return`, el valor devuelto:

```java
import java.sql.Connection;
import java.util.List;

public class Prueba {
    /**
     * Returns a list of names.
     * @param connection a database connection
     * @return the names
     */
    public static List<String> names(Connection connection) {
        return List.of();
    }
}
```

| Opción | Uso |
|---|---|
| `-d docs` | Escribe las páginas en `docs\` (abre `docs\index.html`). |
| `--snippet-path ruta` | Busca archivos externos para insertar fragmentos con `{@snippet file="..."}`; no hace falta para el fragmento en línea del ejemplo. |

```bash
javadoc -d docs Prueba.java
```

- **Snippets** (Java 18+, [JDK Enhancement Proposal (JEP) 413](https://openjdk.org/jeps/413)): una JEP es una propuesta numerada de mejora de OpenJDK. `{@snippet : ... }` inserta código estructurado en un comentario de documentación. Por ejemplo, este comentario puede sustituir al del método en `Prueba.java`:

  ```java
  /**
   * Example: {@snippet :
   *     List<String> names = List.of("Ada");
   * }
   */
  ```

- **Comentarios Markdown** (Java 23+, [JEP 467](https://openjdk.org/jeps/467)): las líneas `///` admiten formato Markdown, como `**negrita**`. Como alternativa, sustituye el comentario del método por:

  ```java
  /// Returns **names**.
  /// @param connection a database connection
  /// @return the names
  ```

## javap — desensamblar bytecode (-c -v -p)

Lee un `.class` para mostrar sus firmas e instrucciones de bytecode (código intermedio que ejecuta la máquina virtual de Java). Compila primero `Prueba.java`:

```bash
javac -d out Prueba.java
```

| Opción | Qué muestra |
|---|---|
| `-c` | Instrucciones desensambladas de los métodos con código. |
| `-v` | Detalles adicionales, como el constant pool y atributos. |
| `-p` | También miembros privados (si los hay). |
| `-classpath out` | Busca `Prueba` en `out\Prueba.class`. |

```bash
javap -classpath out -c -v -p Prueba
```

`javap` inspecciona bytecode, no recupera el fuente original.

## jdeps — análisis de dependencias entre módulos y paquetes

Examina las referencias de clases compiladas: `Prueba` usa `java.sql.Connection` y `java.util.List`. El análisis por paquetes muestra las relaciones concretas; la lista de módulos resume qué módulos del JDK hacen falta.

| Opción | Resultado |
|---|---|
| `-verbose:package` | Dependencias por paquete (por ejemplo, hacia `java.sql` y `java.util`); omite las del mismo paquete por defecto. |
| `--list-deps` | Módulos requeridos (`java.base` y `java.sql` para esta clase). |

```bash
jdeps -verbose:package out
jdeps --list-deps out
```

# Comandos para Linux/macOS

Las rutas usan `/` en vez de `\`; si añades varios elementos al classpath, sepáralos con `:` en lugar de `;`. Los comandos de `javadoc`, `javac`, `javap` y `jdeps` de arriba son idénticos en Linux/macOS porque sus rutas no contienen separadores.
