# javac, java, Lanzamiento de archivo fuente

## javac

**Compilador**: convierte `.java` en `.class` (bytecode).

| Comando | Qué hace |
|---|---|
| `javac Prueba.java` | Genera `Prueba.class` junto al fuente |
| `javac -d out Prueba.java` | `-d`: carpeta donde se **escriben** los `.class` (la crea si no existe) |
| `javac -cp lib\x.jar Prueba.java` | `-cp`: dónde **buscar** clases ya compiladas (classpath); separador `;` |
| `javac --release 17 Prueba.java` | Bytecode **y** API de Java 17; rechaza APIs posteriores |
| `javac -Xlint:all Prueba.java` | Todas las advertencias (`-Xlint:deprecation`, `-Xlint:unchecked`) |
| `javac -parameters Prueba.java` | Guarda nombres de parámetros en el `.class` (reflexión: Spring, Jackson) |

> `--release` reemplaza a `-source` + `-target`: estos solo cambian el bytecode, no validan la API.

> Un `.jar` es un ZIP que agrupa `.class`, recursos y un `META-INF/MANIFEST.MF`.

## java

**Lanzador**: arranca la JVM y ejecuta código ya compilado. Recibe el nombre de la **clase** (`Prueba`), no el archivo.

| Modo | Comando | Dependencias con |
|---|---|---|
| Clase | `java -cp out Prueba` | `-cp` |
| Clase con paquete | `java -cp "out;lib\x.jar" app.Main` | `-cp` |
| JAR | `java -jar app.jar` | `Class-Path` del manifest (ignora `-cp`) |
| Módulo | `java -p mods -m modulo/paquete.Main` | `-p` (module path) |

## Flujo: `-d` y `-cp`

Los comandos son **alternativas**, no una secuencia. Regla: `-d` decide dónde se escribe, `-cp` dónde se busca.

Los ejemplos están en la carpeta `Ejemplos_015`; los comandos se ejecutan desde ahí:

```bash
cd Ejemplos_015
```

`lib\` y `out\` son rutas relativas a esa carpeta.

```bash
javac Prueba.java              # Prueba.class junto al fuente
java Prueba                    # OK: busca en la carpeta actual

javac -d out Prueba.java       # out\Prueba.class
java Prueba                    # ERROR: el .class está en out\
java -cp out Prueba            # OK
```

### Con dependencia (.jar)

```bash
curl.exe -L -o lib\commons-lang3.jar https://repo1.maven.org/maven2/org/apache/commons/commons-lang3/3.17.0/commons-lang3-3.17.0.jar
```

`Prueba.java`:

```java
import org.apache.commons.lang3.StringUtils;

public class Prueba {
    public static void main(String[] args) {
        System.out.println(StringUtils.capitalize("hello world!"));
    }
}
```

```bash
javac -cp lib\commons-lang3.jar -d out Prueba.java  # Apuntando a la carpeta out
javac -cp lib\commons-lang3.jar Prueba.java         # Apuntando a la carpeta donde esta el source
java -cp "out;lib\commons-lang3.jar" Prueba         # imprime: Hello world!
java -cp ".;lib\commons-lang3.jar" Prueba           # el Prueba.class de la carpeta actual (.)
```

> `-cp` **reemplaza** el classpath por defecto (`.`), no lo amplía. Si usas `-cp`, la carpeta actual solo se busca si incluyes `.`. Sin `.`, `java -cp lib\commons-lang3.jar Prueba` da `ClassNotFoundException`. Una `\` inicial (`\lib\...`) apunta a la raíz del disco.

El jar hace falta en **ambos** pasos. Sin él:

| Comando | Error |
|---|---|
| `javac -d out Prueba.java` | `package org.apache.commons.lang3 does not exist` |
| `java -cp out Prueba` | `NoClassDefFoundError` |

## Lanzamiento de archivo fuente único

Desde Java 11 (JEP 330): compila en memoria y ejecuta, sin generar `.class`.

> **JEP** (JDK Enhancement Proposal): documento que propone un cambio del JDK en OpenJDK; se listan en https://openjdk.org/jeps/. El **JEP 330** ("Launch Single-File Source-Code Programs") es el que permite `java Prueba.java`.

```bash
java Prueba.java                                      # compila + ejecuta
java Prueba.java arg1 arg2                            # lo que va después del archivo son args del programa
java -cp ".;lib\commons-lang3.jar" Prueba.java        # con dependencia: -cp va antes del archivo
```

- Ejecuta el `main` de la **primera clase** del archivo.
- Solo para pruebas y scripts.

# Comandos para Linux/macOS

Cambian las rutas (`/`) y el separador del classpath (`:` en vez de `;`).

```bash
cd Ejemplos_015
javac -cp lib/commons-lang3.jar -d out Prueba.java
java -cp out:lib/commons-lang3.jar Prueba
```
