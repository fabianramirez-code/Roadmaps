## Instalación rápida en PowerShell
### Opción 1: winget (instala y gestiona el PATH tú mismo según el paquete)

> ```
> winget search Temurin
> winget install EclipseAdoptium.Temurin.21.JDK
> ```
> Se instala en: **C:\Program Files\Eclipse Adoptium\jdk-27.0.1.0-hotspot\**

### Opción 2: ZIP manual (portable, tú controlas la ruta)
```
$zip = "$env:TEMP\jdk21.zip"
Invoke-WebRequest "<URL-del-ZIP-descargado-de-la-tabla>" -OutFile $zip
Expand-Archive $zip -DestinationPath C:\Java
```
### `JAVA_HOME` y `PATH`


```bash
# Configuración **persistente** para el usuario (no requiere administrador):

$jdk = "C:\Program Files\Eclipse Adoptium\jdk-25.0.5.10002-hotspot"  # Ajusta a tu carpeta real
    [Environment]::SetEnvironmentVariable("JAVA_HOME", $jdk, "User")
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$jdk\bin*") {
    [Environment]::SetEnvironmentVariable("Path", "$jdk\bin;$userPath", "User")}
```

```bash
# Aplicar a la sesión actual (sin cerrar la terminal) y verificar:

$env:JAVA_HOME = $jdk
$env:Path = "$jdk\bin;$env:Path"
java -version
javac -version
```
> **Notas:**
>
> - Para todo el equipo usar `"Machine"` en lugar de `"User"` (PowerShell como administrador).
> - Las terminales ya abiertas **NO** ven el cambio persistente; abre una nueva o usa el bloque de sesión.
> - Ponlo al **inicio** del `Path`: si hay otro `java` instalado (por ejemplo el de Oracle en `C:\Program Files\Common Files\Oracle\Java\javapath`), gana el primero.
> - Para cambiar de versión, repite solo la línea de `JAVA_HOME`; el `Path` ya usa su carpeta `bin` si lo defines con la ruta actual (o usa SDKMAN/Jabba, abajo).

# SDKMAN (https://sdkman.io/)

Gestor de (Software Development Kit) SDKs (Java, Maven, Gradle, Kotlin, Spring Boot CLI…). Instala varias versiones y cambia entre ellas con un comando. 

> **Windows:** SDKMAN es un conjunto de scripts bash; **no funciona en PowerShell nativo**. Úsalo en **WSL** o **Git Bash**. En Linux/macOS funciona directamente.

```bash
# Instalar
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk version

# Listar y instalar JDKs
sdk list java                    # muestra distribuciones (Temurin, Corretto, Zulu, Oracle…) y versiones
sdk install java 21.0.5-tem      # Temurin 21 (sufijo -tem)
sdk install java 21.0.5-amzn     # Corretto (sufijo -amzn)

# Usar
sdk use java 21.0.5-tem          # solo en la terminal actual
sdk default java 21.0.5-tem      # por defecto en todas las terminales
sdk current java                 # versión activa
sdk uninstall java 21.0.5-tem

# Otras herramientas
sdk install maven
sdk install gradle
```

> **Por proyecto:** `sdk env init` crea un archivo `.sdkmanrc`; luego `sdk env` activa las versiones declaradas ahí.

# Jabba

Gestor de versiones de JDK multiplataforma que **SI** funciona en **PowerShell nativo**. Repo: https://github.com/Jabba-Team/jabba

> 👁️ El proyecto original (`shyiko/jabba`) está abandonado y el mantenimiento actual es de la comunidad, con poca actividad. Para Windows nativo es una opción válida; si buscas algo con más soporte, usa SDKMAN en WSL o `winget`.

```bash
# Instalar (verifica el script en el README del repo antes de ejecutarlo)

Invoke-Expression (
  Invoke-WebRequest https://github.com/Jabba-Team/jabba/raw/main/install.ps1 -UseBasicParsing
).Content
```

`jabba --version` 

### Listar e instalar versiones
```bash 
jabba ls-remote | Select-String temurin@21   # ES MEJOR ESTE PARA BUSCAR POR VERSION
jabba install temurin@21.0.11                # LO INSTALAS
#Se quedan instalados en: "C:\Users\fabia\scoop\persist\jabba\jdk\"
```

### Para pruebas con versiones viejas (nombres verificados en ls-remote):
```
jabba install temurin@11.0.31     # Java 11
jabba install zulu@8.0.492        # Java 8 (Jabba NO tiene Temurin 8 → usar Zulu)
```

### Aliases (para no escribir la versión completa)
```bash
jabba ls                              # Instaladas
jabba alias j11 temurin@11.0.31       # Solo en la sesión actual
jabba alias default temurin@11.0.31   # Por defecto (se activa en cada terminal nueva)
jabba alias j8  zulu@8.0.492
jabba use j11                         # USAR CON EL ALIAS
``` 

### Otros
``` bash
jabba which j11                       # Donde esta instalado ( via alias)
jabba which temurin@11.0.31           # Donde esta instalado
jabba uninstall temurin@11.0.31       
```

> **Jabba ajusta `JAVA_HOME` y `PATH` por sesión, así que no necesitas editar variables a mano.**
