# Formato de número de versión

`Runtime.version()`, esquema `feature.interim.update.patch`

## Esquema (JEP 223, desde Java 9)

```
$FEATURE.$INTERIM.$UPDATE.$PATCH
```

| Campo | Significado | Cuándo cambia |
|---|---|---|
| `FEATURE` | Versión mayor del lenguaje/plataforma (17, 21, 25) | Cada 6 meses (marzo y septiembre) |
| `INTERIM` | Versión intermedia | Siempre `0` en la práctica actual |
| `UPDATE` | Actualización de seguridad/correcciones | Con cada actualización trimestral (CPU) |
| `PATCH` | Parche de emergencia fuera de ciclo | Solo cuando es necesario |

Los ceros finales se omiten: `21.0.5` en lugar de `21.0.5.0`, y `25` en lugar de `25.0.0`.

Formato completo de la cadena:

```
$VNUM(-$PRE)?(\+$BUILD)?(-$OPT)?
```

Ejemplo: `21.0.5+11-LTS`

- `21.0.5` → `VNUM` (feature 21, interim 0, update 5)
- `+11` → número de build
- `-LTS` → opcional, lo añade el distribuidor (también `-ea` para *early access*)

## Antes de Java 9

Java 8 y anteriores usaban otro formato, por eso confunde:

| Cadena | Significado |
|---|---|
| `1.8.0_432` | Java 8, update 432 |
| `1.7.0_80` | Java 7, update 80 |

Desde Java 9 desapareció el prefijo `1.`: se escribe `11`, `17`, `21`.

## `Runtime.version()`

```java
Runtime.Version v = Runtime.version();

System.out.println(v);            // 21.0.5+11-LTS
System.out.println(v.feature());  // 21
System.out.println(v.interim());  // 0
System.out.println(v.update());   // 5
System.out.println(v.patch());    // 0
System.out.println(v.build());    // Optional[11]
```

- `feature()`, `interim()`, `update()` y `patch()` existen desde Java 10. En Java 9 se usaban `major()`, `minor()` y `security()`, hoy deprecados.
- `Runtime.version()` no existe en Java 8: ahí lee la propiedad `System.getProperty("java.version")`.
- Para comparar versiones usa `Runtime.Version.parse("21.0.5")` y `compareTo`, no compares strings.

## Propiedades útiles

```java
System.getProperty("java.version");          // "21.0.5"
System.getProperty("java.specification.version"); // "21" (versión de la especificación Java SE)
System.getProperty("java.vendor");           // distribución (Eclipse Adoptium, Amazon.com Inc., …)
```

> `java.version` puede traer sufijos según el distribuidor; usa `java.specification.version` o `Runtime.version().feature()` cuando solo te importe la versión mayor.
