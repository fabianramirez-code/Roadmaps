# Azul Zulu, BellSoft Liberica, Microsoft Build of OpenJDK
# Azul Zulu — builds y soporte comercial
**Azul Zulu Builds of OpenJDK** son distribuciones gratuitas, de código abierto y certificadas (TCK) de OpenJDK, disponibles para **Linux, Windows, macOS** y arquitecturas como x86, ARM y SPARC. Estas compilaciones son gratuitas para uso comercial y producción, ofreciendo soporte comunitario y parches de seguridad trimestrales bajo la licencia GPL+CE.

>Para necesidades empresariales, Azul Core proporciona el soporte comercial asociado a estas compilaciones, ofreciendo:
>
>- **SLA garantizados:** Soporte técnico con tiempos de respuesta definidos (24x7x365 en tier Premium).
>- **Parches de seguridad:** Actualizaciones estables y priorizadas fuera del ciclo trimestral estándar si es necesario.
>- **Soporte experto:** Acceso a ingenieros especializados en JVM y gerentes técnicos asignados.
>
>Existe también **Azul Prime**, un producto comercial separado que utiliza el motor de rendimiento **Zing** (con recolector C4) para cargas de trabajo de alto rendimiento, diferenciándose de Zulu que se basa en el motor HotSpot estándar.

# BellSoft Liberica — incluye variantes con JavaFX

**BellSoft Liberica JDK** es una distribución gratuita y de código abierto de OpenJDK, certificada por TCK y respaldada por BellSoft, que se destaca por ofrecer variantes específicas para diferentes necesidades de desarrollo, incluyendo una versión completa con **JavaFX** integrado.
>**JavaFX** es una plataforma de software open source diseñada para crear **aplicaciones de escritorio**.
> 
> *Desde la versión 11 de Java, JavaFX se separó del JDK principal, evolucionando como un proyecto independiente que garantiza actualizaciones continuas y soporte para las últimas versiones de Java*

La distribución se divide en tres sabores principales:

- **Standard:** Para uso general de Java sin componentes adicionales.
- **Lite:** Optimizada para reducir la huella de memoria, ideal para contenedores y entornos cloud.
- **Full:** Incluye LibericaFX (una instancia de OpenJFX), permitiendo el desarrollo de aplicaciones con interfaz gráfica (JavaFX) sin necesidad de descargar o configurar bibliotecas externas.

- A diferencia de las versiones estándar de OpenJDK (desde la versión 11), **las compilaciones Full de Liberica JDK empacan los módulos de JavaFX directamente en la imagen del entorno de ejecución**, facilitando su uso en sistemas Windows, macOS, Linux y arquitecturas ARM.

# Microsoft Build of OpenJDK

**Microsoft Build of OpenJDK** es una distribución de código abierto y sin costo de OpenJDK, disponible gratuitamente para implementarse en cualquier lugar.  Incluye binarios de **Soporte a Largo Plazo (LTS)** para Java 11, Java 17, Java 21 y Java 25, optimizados para entornos de servidor y escritorio en macOS, Linux y Windows, así como para arquitecturas **AArch64/ARM64 y Apple Silicon (M1)**.

Los binarios se basan en el código fuente de OpenJDK, utilizando los mismos scripts de compilación del proyecto Eclipse Adoptium y pasando por su suite de aseguramiento de calidad **AQAvit** y el **Kit de Compatibilidad de Tecnología Java (TCK) de Oracle**.  Esto garantiza que sea una reemplazo directo (drop-in replacement) para cualquier otra distribución de OpenJDK en el ecosistema de Java.

>*Eclipse AQAvit es un proyecto de la Fundación Eclipse dedicado a la evaluación de calidad y certificación de tiempos de ejecución de Java SE. Su objetivo es garantizar que los binarios de OpenJDK cumplan con estándares excepcionales de rendimiento, seguridad y confiabilidad para entornos de producción mediante una suite de pruebas rigurosa*.

- **Licencia:** GPLv2 con Excepción de Clase (GPLv2+CE).
- **Ventajas clave:** Permite a Microsoft acelerar la entrega de **correcciones de seguridad y mejoras** (backports) importantes para sus clientes y usuarios internos, las cuales pueden no estar dispossnibles inmediatamente en la versión upstream original.
- **Integración:** Es la distribución predeterminada para servicios gestionados de Java en **Microsoft Azure* y se utiliza internamente por Microsoft para más de 500,000 máquinas virtuales Java (JVM).
