# ArrayList, LinkedList, ArrayDeque

> Phase: [[Java 05 - Genericos y colecciones|Java 05 - Generics and Collections]] · Topic: Implementations and internals

## Roadmap reference

| Implementation | Structure | Key operations |
|---|---|---|
| `ArrayList` | Resizable array | get O(1), amortized add O(1), middle insert/remove O(n) |
| `LinkedList` | Doubly linked list | access O(n), add/remove at ends O(1) |
| `ArrayDeque` | Circular array | push/pop/offer/poll O(1) |
| `PriorityQueue` | Binary heap | offer/poll O(log n), peek O(1) |
| `HashMap` | Hash table + trees | average get/put O(1), O(log n) with treeification |
| `LinkedHashMap` | Hash + linked list | insertion or access order (least recently used, LRU) |
| `TreeMap` | Red-black tree | O(log n), natural order |
| `HashSet` / `TreeSet` | Backed by `HashMap`/`TreeMap` | same as their map |
| `EnumMap` | Ordinal-indexed array | O(1) |
| `IdentityHashMap` | Compares by `==` | O(1) |
| `WeakHashMap` | Weak keys | cleanup by garbage collection (GC) |
