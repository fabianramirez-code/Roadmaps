# Knowledge questions, practice and common mistakes

> Phase: [[Java 05 - Genericos y colecciones|Java 05 - Generics and Collections]]

## Knowledge questions

1. How does `HashMap.put` work from hashing to treeification?
2. What happens during resizing, and what is its cost?
3. What is Producer Extends, Consumer Super (PECS), and when is it applied?
4. What are the consequences of type erasure?
5. Why can you not create `new List<String>[10]`?
6. When should you use `LinkedList` instead of `ArrayList`?
7. What is the difference between `unmodifiableList` and `List.of`?
8. What is fail-fast behavior, and how can you avoid `ConcurrentModificationException`?
9. What contract does `TreeMap` require of its keys?
10. What do Sequenced Collections add, and since which version?
11. What is heap pollution?
12. How do you implement a least recently used (LRU) cache with `LinkedHashMap`?

## Practice

1. Implement `MyArrayList<T>` and `MyHashMap<K,V>` with tests.
2. Write a generic `max` method with a recursive bound and another using wildcards (PECS).
3. Benchmark `ArrayList` vs `LinkedList` vs `ArrayDeque` with Java Microbenchmark Harness (JMH) (see [[Java 09 - JVM por dentro|Java 09 - JVM Internals]]).
4. Create a `HashMap` key with a poor `hashCode` and observe its performance impact.
5. Implement an LRU cache with `LinkedHashMap`.
6. Solve 15 data-structure problems, choosing and justifying a collection for each.
7. Reproduce `ConcurrentModificationException` and fix it three ways.
8. Implement Dijkstra's algorithm with `PriorityQueue`.

## Common mistakes

- Using raw types (`List` without a type parameter).
- Mutating a `HashMap` key after inserting it.
- Making `hashCode` inconsistent with `equals`.
- Calling `add` after `Arrays.asList` (throws an exception).
- Removing elements inside an enhanced `for` loop.
- Assuming `HashMap` preserves order.
- Using `Stack`/`Vector`/`Hashtable` in new code.
- Passing `null` elements to `List.of`.
- Choosing `LinkedList` for "fast insertions" without measuring.
- Using a comparator that subtracts integers (overflow).
