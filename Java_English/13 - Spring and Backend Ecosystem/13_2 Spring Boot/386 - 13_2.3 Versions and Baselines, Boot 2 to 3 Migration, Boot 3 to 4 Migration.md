# Versions and Baselines, Boot 2 to 3 Migration, Boot 3 to 4 Migration

> Phase: [[Java 13 - Spring y ecosistema backend|Java 13 - Spring and Backend Ecosystem]] · Topic: Spring Boot

## Versions and Baselines

> Boot 3.x (Java 17+), Boot 4.0/4.1 (Jakarta EE 11, Java 17+)

## Boot 2 to 3 Migration

> `javax.*` to `jakarta.*`, Java 17, Hibernate 6

## Boot 3 to 4 Migration

> Jackson 3 (`tools.jackson`), JUnit 4 removed, Undertow removed, modularized jars
