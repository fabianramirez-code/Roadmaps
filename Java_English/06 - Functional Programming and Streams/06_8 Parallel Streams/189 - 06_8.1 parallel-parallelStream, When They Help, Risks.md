# parallel-parallelStream, when they help, risks

> Phase: [[Java 06 - Programacion funcional y Streams|Java 06 - Functional Programming and Streams]] · Topic: Parallel streams

## parallel()/parallelStream() and ForkJoinPool.commonPool

## When they help

> large datasets, expensive stateless operations, sources that split well

## Risks

> blocking I/O, shared state, ordering, contention in the common pool
