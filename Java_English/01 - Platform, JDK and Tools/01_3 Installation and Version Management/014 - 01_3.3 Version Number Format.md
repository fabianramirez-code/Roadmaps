# Version number format

`Runtime.version()`, `feature.interim.update.patch` scheme

## Scheme (JEP 223, since Java 9)

```
$FEATURE.$INTERIM.$UPDATE.$PATCH
```

| Field | Meaning | When it changes |
|---|---|---|
| `FEATURE` | Major language/platform version (17, 21, 25) | Every 6 months (March and September) |
| `INTERIM` | Interim version | Always `0` in current practice |
| `UPDATE` | Security update/fixes | With each quarterly update (CPU) |
| `PATCH` | Out-of-cycle emergency patch | Only when needed |

Trailing zeros are omitted: `21.0.5` instead of `21.0.5.0`, and `25` instead of `25.0.0`.

Full string format:

```
$VNUM(-$PRE)?(\+$BUILD)?(-$OPT)?
```

Example: `21.0.5+11-LTS`

- `21.0.5` → `VNUM` (feature 21, interim 0, update 5)
- `+11` → build number
- `-LTS` → optional, added by the distributor (also `-ea` for *early access*)

## Before Java 9

Java 8 and earlier used a different format, which can be confusing:

| String | Meaning |
|---|---|
| `1.8.0_432` | Java 8, update 432 |
| `1.7.0_80` | Java 7, update 80 |

Since Java 9 the `1.` prefix has disappeared: write `11`, `17`, `21`.

## `Runtime.version()`

```java
Runtime.Version v = Runtime.version();

System.out.println(v);            // 21.0.5+11-LTS
System.out.println(v.feature());  // 21
System.out.println(v.interim());  // 0
System.out.println(v.update());   // 5
System.out.println(v.patch());    // 0
System.out.println(v.build());    // Optional[11]
```

- `feature()`, `interim()`, `update()` and `patch()` have existed since Java 10. Java 9 used `major()`, `minor()` and `security()`, now deprecated.
- `Runtime.version()` does not exist in Java 8: there, read the `System.getProperty("java.version")` property.
- To compare versions, use `Runtime.Version.parse("21.0.5")` and `compareTo`; do not compare strings.

## Useful properties

```java
System.getProperty("java.version");          // "21.0.5"
System.getProperty("java.specification.version"); // "21" (Java SE specification version)
System.getProperty("java.vendor");           // distribution (Eclipse Adoptium, Amazon.com Inc., …)
```

> `java.version` can have suffixes depending on the distributor; use `java.specification.version` or `Runtime.version().feature()` when only the major version matters.
