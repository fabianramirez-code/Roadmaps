# Install a JDK manually, SDKMAN, Jabba

## Quick comparison
| | Manual | SDKMAN | Jabba |
|---|---|---|---|
| Native Windows | Yes | No (WSL / Git Bash) | Yes |
| Multiple versions | Manual | Yes | Yes |
| Other tools (Maven, Gradle) | No | Yes | No |
| Maintenance | — | Active | Community-run, low activity |

## Quick installation in PowerShell
### Option 1: winget (install and manage PATH yourself depending on the package)

> ```
> winget search Temurin
> winget install EclipseAdoptium.Temurin.21.JDK
> ```
> Installs to: **C:\Program Files\Eclipse Adoptium\jdk-27.0.1.0-hotspot\**

### Option 2: manual ZIP (portable, you control the path)
```
$zip = "$env:TEMP\jdk21.zip"
Invoke-WebRequest "<URL-of-ZIP-downloaded-from-table>" -OutFile $zip
Expand-Archive $zip -DestinationPath C:\Java
```
### `JAVA_HOME` and `PATH`


```bash
# **Persistent** configuration for the user (no administrator required):

$jdk = "C:\Program Files\Eclipse Adoptium\jdk-25.0.5.10002-hotspot"  # Adjust to your actual folder
    [Environment]::SetEnvironmentVariable("JAVA_HOME", $jdk, "User")
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$jdk\bin*") {
    [Environment]::SetEnvironmentVariable("Path", "$jdk\bin;$userPath", "User")}
```

```bash
# Apply to the current session (without closing the terminal) and verify:

$env:JAVA_HOME = $jdk
$env:Path = "$jdk\bin;$env:Path"
java -version
javac -version
```
> **Notes:**
>
> - To configure the whole machine, use `"Machine"` instead of `"User"` (PowerShell as administrator).
> - Already-open terminals **DO NOT** see the persistent change; open a new one or use the session block.
> - Put it at the **start** of `Path`: if another `java` is installed (for example Oracle's at `C:\Program Files\Common Files\Oracle\Java\javapath`), the first one wins.
> - To switch versions, repeat only the `JAVA_HOME` line; `Path` already uses its `bin` folder if you define it with the current path (or use SDKMAN/Jabba below).

# SDKMAN (https://sdkman.io/)

A manager for Software Development Kits (SDKs) (Java, Maven, Gradle, Kotlin, Spring Boot CLI…). Installs multiple versions and switches between them with one command.

> **Windows:** SDKMAN is a set of bash scripts; it **does not work in native PowerShell**. Use it in **WSL** or **Git Bash**. It works directly on Linux/macOS.

```bash
# Install
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk version

# List and install JDKs
sdk list java                    # shows distributions (Temurin, Corretto, Zulu, Oracle…) and versions
sdk install java 21.0.5-tem      # Temurin 21 (-tem suffix)
sdk install java 21.0.5-amzn     # Corretto (-amzn suffix)

# Use
sdk use java 21.0.5-tem          # only in the current terminal
sdk default java 21.0.5-tem      # default in all terminals
sdk current java                 # active version
sdk uninstall java 21.0.5-tem

# Other tools
sdk install maven
sdk install gradle
```

> **Per project:** `sdk env init` creates a `.sdkmanrc` file; then `sdk env` activates the versions declared there.

# Jabba

A cross-platform JDK version manager that **DOES** work in **native PowerShell**. Repository: https://github.com/Jabba-Team/jabba

> 👁️ The original project (`shyiko/jabba`) is abandoned; current maintenance is community-run with little activity. It is a valid choice for native Windows; if you want more support, use SDKMAN in WSL or `winget`.

```bash
# Install (check the script in the repository README before running it)

Invoke-Expression (
  Invoke-WebRequest https://github.com/Jabba-Team/jabba/raw/main/install.ps1 -UseBasicParsing
).Content
```

`jabba --version`

### List and install versions
```bash
jabba ls-remote | Select-String temurin@21   # BEST FOR SEARCHING BY VERSION
jabba install temurin@21.0.11                # INSTALL IT
#Installed in: "C:\Users\fabia\scoop\persist\jabba\jdk\"
```

### For testing older versions (names verified with ls-remote):
```
jabba install temurin@11.0.31     # Java 11
jabba install zulu@8.0.492        # Java 8 (Jabba DOES NOT have Temurin 8 → use Zulu)
```

### Aliases (to avoid typing the full version)
```bash
jabba ls                              # Installed
jabba alias j11 temurin@11.0.31       # Only in the current session
jabba alias default temurin@11.0.31   # Default (activated in every new terminal)
jabba alias j8  zulu@8.0.492
jabba use j11                         # USE THE ALIAS
```

### Others
``` bash
jabba which j11                       # Where installed (via alias)
jabba which temurin@11.0.31           # Where installed
jabba uninstall temurin@11.0.31
```

> **Jabba adjusts `JAVA_HOME` and `PATH` per session, so you do not need to edit variables manually.**
