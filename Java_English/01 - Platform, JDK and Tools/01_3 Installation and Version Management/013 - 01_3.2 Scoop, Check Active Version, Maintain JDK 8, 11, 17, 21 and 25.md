# Scoop, Check active version, Maintain JDK 8, 11, 17, 21 and 25

# Scoop (https://scoop.sh/)
A Windows package manager that installs in your user folder (`~\scoop`), without administrator access.

> JDKs live in the **`java`** bucket: https://github.com/ScoopInstaller/Java

```bash
# Install Scoop
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

# Add the Java bucket
scoop bucket add java

# Search and install
scoop search temurin
scoop install temurin21-jdk
scoop install corretto21-jdk     # other distributions: zulu21-jdk, oraclejdk, openjdk, etc.

# Maintenance
scoop list                       # installed
scoop update                     # updates Scoop and buckets
scoop update temurin21-jdk       # updates one package
scoop uninstall temurin21-jdk
```

- Scoop puts each JDK in `~\scoop\apps\<package>\current` and manages the user's `JAVA_HOME` and `PATH` for you.
- Exact package names change over time: confirm them with `scoop search`.

## Check active version

```bash
java -version        # works in all versions (prints to stderr)
javac -version       # compiler: confirms it is a JDK and not just a JRE
java --version       # Java 9+ only; on Java 8 fails with "Unrecognized option"

echo $env:JAVA_HOME  # which JDK your environment thinks it uses
where.exe java       # all java executables on PATH; the first is the one run
```

> If `java -version` and `JAVA_HOME` disagree, the **first `java` on `PATH`** takes precedence, not `JAVA_HOME`. Many tools (Maven, Gradle, IDEs), however, read `JAVA_HOME`, so both should point to the same JDK.

## Maintain JDK 8, 11, 17, 21 and 25 in parallel

Useful for reproducing legacy code and testing compatibility across LTS releases.

```bash
# Install all five LTS versions
scoop install temurin8-jdk temurin11-jdk temurin17-jdk temurin21-jdk temurin25-jdk

# Switch the active version (reassigns `current`, JAVA_HOME and PATH)
scoop reset temurin8-jdk
java -version                    # 1.8.0_xxx

scoop reset temurin21-jdk
java -version                    # 21.x
```

Use a version **only in this terminal**, without changing the global configuration:

```bash
$env:JAVA_HOME = "$env:USERPROFILE\scoop\apps\temurin17-jdk\current"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
java -version
```

Useful conventions:

- Keep the LTS you use daily (currently 21 or 25) as the **default**, and switch to an older version only when reproducing a bug.
- Each project sets its version in the build (`maven.compiler.release`, Gradle toolchains), not in the environment.
- Java 8 reports its version as `1.8.0_xxx`; since Java 9 it is `9`, `11`, `17`…
- Equivalent alternatives: SDKMAN (`sdk use java …`) or Jabba, covered in the previous note.
