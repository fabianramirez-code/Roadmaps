# Multi-File Source Launch, jshell, jar

# Multi-file source launch

Since Java 22, [JDK Enhancement Proposal (JEP) 458](https://openjdk.org/jeps/458) lets you launch a program consisting of several `.java` files without generating `.class`: Java compiles the initial file in memory and finds the other sources by name in the same directory, respecting packages. A JEP is a numbered JDK improvement proposal. Java 11–21 single-file launch is explained in note 015; in those versions, use `javac` for multiple sources.

Create `Main.java` and `Greeting.java`:

```java
// Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(Greeting.from("Java"));
    }
}
```

```java
// Greeting.java
public class Greeting {
    static String from(String name) { return "Hello " + name; }
}
```

```bash
java Main.java # Hello Java (Java 22+)
```

Launch only the file with `main`; the others are found by class name.

## jshell

Since Java 9, [JEP 222](https://openjdk.org/jeps/222) includes `jshell`, a Read-Eval-Print Loop (REPL): it reads an instruction, evaluates it and displays the result without a class or `main`. Use it to try code quickly ([jshell manual](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jshell.html)).

```bash
jshell
```

In the session, type the following (`jshell>` is the prompt, not part of the input):

```text
jshell> int x = 5
jshell> x * 2
jshell> List.of(1, 2, 3)
jshell> /vars
jshell> /exit
```

Expressions display their value and can create temporary variables; `java.util` is imported by default. `/vars` displays defined variables and `/exit` closes the session. Other useful commands: `/methods` (methods), `/imports` (active imports), `/list` (entered snippets) and `/help` (help).

## jar

Java Archive (JAR) is a compressed ZIP containing `.class` files, resources and a `META-INF/MANIFEST.MF` manifest for distributing code. The `jar` tool creates, lists or extracts it ([jar manual](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jar.html)).

| Option | Function |
|---|---|
| `-C out .` | Includes the contents of `out` without prefixing entries with `out/`. |
| `--main-class Main` | Writes `Main-Class: Main` in the manifest to permit execution. |

Compile both sources and package the main class:

```bash
javac -d out Main.java Greeting.java
jar --create --file app.jar --main-class Main -C out .
java -jar app.jar # Hello Java
jar --list --file app.jar # Lists JAR entries, including META-INF/MANIFEST.MF
```

Equivalent short forms to create, list and extract, respectively: `jar cfe app.jar Main -C out .`, `jar tf app.jar`, `jar xf app.jar`.

> To inspect the manifest without scattering extracted files, create the `extracted` directory yourself:

```bash
mkdir extracted
cd extracted
jar --extract --file ..\app.jar
Get-Content META-INF\MANIFEST.MF
cat META-INF\MANIFEST.MF # The manifest can also be read with cat
```

When running a JAR, `java -jar` ignores `-cp`; for external dependencies, the manifest's `Class-Path` attribute must specify paths relative to the JAR (see also note 015).

# Linux/macOS Commands

Paths use `/` instead of `\` (`../app.jar` and `META-INF/MANIFEST.MF`); use `cat` instead of `Get-Content` to display the manifest. The other Java commands do not change.
