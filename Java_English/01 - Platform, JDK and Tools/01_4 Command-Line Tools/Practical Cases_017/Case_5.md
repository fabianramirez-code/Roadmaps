# Case 5: verify that the compiler honored `--release`

## The problem
You want code to run on a specific JVM (for example Java 11) even though you compile with a newer JDK. `--release N` does two things: sets the bytecode `major version` and limits the visible API to Java N. `-source N -target N` only does the first: it compiles against the installed JDK's API, so a method newer than N compiles but fails at runtime with `NoSuchMethodError` (case 2).

## Minimal example
`Stream.toList()` has existed since Java 16:

```java
import java.util.List;
import java.util.stream.Stream;

public class Release {
    public static void main(String[] args) {
        List<String> list = Stream.of("a", "b").toList();
        System.out.println(list);
    }
}
```

## 1. `--release` rejects the unavailable API
```bash
javac --release 11 -d out Release.java
```

Compilation fails with `cannot find symbol ... method toList()`: the error occurs on your machine, not in production. With `--release 17`, it compiles.

## 2. Verify generated bytecode
```bash
javac --release 17 -d out Release.java
javap -classpath out -v Release | Select-String "major version"
```

Result: `major version: 61` (Java 17). Version table in case 1 (`major = Java + 44`).

## 3. Compare with `-source`/`-target`
```bash
javac -source 11 -target 11 -d out Release.java
```

It compiles (with a warning about the *bootstrap classpath*) because it uses the current JDK API. `javap` shows `major version: 55`, but the bytecode references `Stream.toList()`, which a Java 11 JVM lacks: it fails at runtime with `NoSuchMethodError`. A correct `major` does not guarantee API compatibility; only `--release` ensures that.

## When to apply it
- Before publishing a library or deploying: check that `major` matches the promised version.
- In CI audits: scan JAR `.class` files with `javap -v` and fail if `major` exceeds the target.
- During migration: confirm that the build really uses `--release` (Maven: `maven.compiler.release`; Gradle: `options.release`).

# Linux/macOS Commands
```bash
javap -classpath out -v Release | grep "major version"
```
