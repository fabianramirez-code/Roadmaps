# jdeprscan, jlink, jpackage

## jdeprscan — detect deprecated API usage

An Application Programming Interface (API) is the set of classes and methods a library offers. `jdeprscan` finds references to **deprecated** APIs in compiled code: methods still present but discouraged, some marked for removal ([jdeprscan manual](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jdeprscan.html)). It accepts a `.class` file, a class directory or a Java Archive (JAR), which packages classes and resources.

| Option | Function |
|---|---|
| `--release 25` | Checks Java 25 deprecations; use a version supported by your `jdeprscan --help`. |
| `--for-removal` | Restricts results to APIs marked for removal. |
| `--list` | Lists deprecated APIs in the selected version **without analyzing files**. |
| `-v` | Shows more analysis detail; may produce much output. |

Reuse the idea of `Test.java` from note 017 (`java.sql.Connection` and `java.util.List`) and add a deprecated method **that is never run**. Create this single file in `Examples_018`:

```java
import java.sql.Connection;
import java.util.List;

public class Test {
    public static List<String> names(Connection connection) {
        return List.of();
    }

    public static void obsolete(Thread thread) {
        thread.stop();
    }

    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

`Thread.stop()` is marked for removal: the compiler warns and `jdeprscan` detects the reference even when the method is never called. Do not run `obsolete`: in current versions `stop()` throws an exception.

```bash
javac -d input Test.java                       # Creates input\Test.class; emits a warning
jdeprscan --release 25 --for-removal input       # Detects Thread.stop() in the directory
jdeprscan --release 25 -v input\Test.class     # Analyzes one class in more detail
jdeprscan --release 25 --list                    # Lists deprecated APIs, with no input path
```

## jlink — custom runtime

Available since Java 9 ([JDK Enhancement Proposal (JEP) 282](https://openjdk.org/jeps/282)); a JEP is a numbered proposal to improve the Java Development Kit (JDK). `jlink` **assembles modules and dependencies into an executable Java image without including the whole JDK** ([jlink manual](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jlink.html)). It normally uses modules from the JDK's `jmods` directory; [JEP 493](https://openjdk.org/jeps/493) enabled linking from a runtime image without Java Module (JMOD) files in Java 24, given the required capabilities. Do not assume every older runtime can be used for linking.

| Option | Function |
|---|---|
| `--add-modules java.base,java.sql` | Root modules; `jlink` includes their dependencies too. |
| `--output runtime` | **New** directory in which to create the image. |
| `--strip-debug` | Omits debugging information. |
| `--compress zip-6` | Compresses resources (Java 25 syntax; check `jlink --help` on other versions). |
| `--no-header-files` / `--no-man-pages` | Omits native headers / manual pages. |

Note 017 uses `jdeps --list-deps` to obtain required modules; here it shows `java.base` and `java.sql`. `--list-modules` belongs to **`java`**, not `jlink`: it checks modules in the image, including transitive ones.

```bash
jdeps --list-deps input
jlink --add-modules java.base,java.sql --output runtime --strip-debug --compress zip-6 --no-header-files --no-man-pages # Creates runtime
.\runtime\bin\java --list-modules # Lists modules
(Get-ChildItem runtime -Recurse -File | Measure-Object -Property Length -Sum).Sum / 1MB # File size in MiB
```

## jpackage — native application and installer

Incubated in Java 14 and finalized in Java 16 ([JEP 392](https://openjdk.org/jeps/392)), `jpackage` distributes an application **with** a runtime: **it can create an application image (`app-image`) or a native installer** ([jpackage manual](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jpackage.html)). `jlink` only builds the runtime; `jpackage` bundles it with the application and, with `exe` or `msi` on Windows, generates an installer. Those installers require [WiX Toolset](https://docs.oracle.com/en/java/javase/25/jpackage/packaging-overview.html); `app-image` does not.

| Option | Function |
|---|---|
| `--input input` | Directory containing the JAR and other application files. |
| `--main-jar Test.jar` | Main JAR, relative to `--input`. |
| `--main-class Test` | JAR's main class. |
| `--name TestApp` | Application and launcher name. |
| `--type app-image` | Creates an executable directory; `exe` / `msi` make Windows installers with WiX Toolset. |
| `--runtime-image runtime` | Reuses the `jlink` image; if omitted, `jpackage` invokes `jlink`. |
| `--dest output` | Destination directory. |

Package and test the image using the preceding files. `--win-console` makes this console application's output visible on Windows.

```bash
jar --create --file input\Test.jar --main-class Test -C input Test.class
jdeprscan --release 25 --for-removal input\Test.jar # Also accepts JARs

# Use native app-image
jpackage --type app-image --input input --main-jar Test.jar --main-class Test --name TestApp --runtime-image runtime --dest output --win-console # Creates the .exe

# WiX is required; only --type changes to msi/exe for the installer
jpackage --type msi --input input --main-jar Test.jar --main-class Test --name TestApp --runtime-image runtime --dest output --win-console # Creates the .msi

.\output\TestApp\TestApp.exe # Hello Java
```

# Linux/macOS Commands

Only path separators, launcher and Windows-only console option differ. Omit `--win-console` with `jpackage`:

```bash
jdeprscan --release 25 -v input/Test.class
jar --create --file input/Test.jar --main-class Test -C input Test.class
jdeprscan --release 25 --for-removal input/Test.jar
jpackage --type app-image --input input --main-jar Test.jar --main-class Test --name TestApp --runtime-image runtime --dest output
./output/TestApp/bin/TestApp # Linux: Hello Java
./output/TestApp.app/Contents/MacOS/TestApp # macOS: Hello Java
./runtime/bin/java --list-modules
du -sh runtime # Disk space used by the image
```
