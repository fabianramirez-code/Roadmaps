# Azul Zulu, BellSoft Liberica, Microsoft Build of OpenJDK
# Azul Zulu — builds and commercial support
**Azul Zulu Builds of OpenJDK** are free, open-source and certified (TCK) OpenJDK distributions available for **Linux, Windows, macOS** and architectures including x86, ARM and SPARC. These builds are free for commercial and production use, with community support and quarterly security patches under the GPL+CE license.

>For enterprise needs, Azul Core provides associated commercial support for these builds, offering:
>
>- **Guaranteed SLAs:** Technical support with defined response times (24x7x365 in the Premium tier).
>- **Security patches:** Stable, prioritized updates outside the standard quarterly cycle when necessary.
>- **Expert support:** Access to specialized JVM engineers and assigned technical account managers.
>
>There is also **Azul Prime**, a separate commercial product using the **Zing** performance engine (with the C4 collector) for high-performance workloads, unlike Zulu, which uses the standard HotSpot engine.

# BellSoft Liberica — includes JavaFX variants

**BellSoft Liberica JDK** is a free, open-source OpenJDK distribution, TCK certified and backed by BellSoft, notable for offering variants for different development needs, including a full version with integrated **JavaFX**.
>**JavaFX** is an open-source software platform designed to create **desktop applications**.
>
> *Since Java 11, JavaFX has been separated from the main JDK, evolving as an independent project that ensures continuing updates and support for the latest Java versions.*

The distribution comes in three main flavors:

- **Standard:** For general Java use without additional components.
- **Lite:** Optimized for a smaller memory footprint, ideal for containers and cloud environments.
- **Full:** Includes LibericaFX (an instance of OpenJFX), enabling graphical user interface (JavaFX) application development without downloading or configuring external libraries.

- Unlike standard OpenJDK versions (since version 11), **Liberica JDK Full builds package JavaFX modules directly into the runtime image**, making them easier to use on Windows, macOS, Linux and ARM architectures.

# Microsoft Build of OpenJDK

**Microsoft Build of OpenJDK** is a free, open-source OpenJDK distribution available for deployment anywhere at no cost. It includes **Long-Term Support (LTS)** binaries for Java 11, Java 17, Java 21 and Java 25, optimized for server and desktop environments on macOS, Linux and Windows, as well as **AArch64/ARM64 and Apple Silicon (M1)** architectures.

The binaries are based on OpenJDK source code, use the same build scripts as the Eclipse Adoptium project, and pass its **AQAvit** quality assurance suite and Oracle's **Java Technology Compatibility Kit (TCK)**. This ensures they are a drop-in replacement for any other OpenJDK distribution in the Java ecosystem.

>*Eclipse AQAvit is an Eclipse Foundation project dedicated to quality evaluation and certification of Java SE runtimes. Its goal is to ensure that OpenJDK binaries meet exceptional performance, security and reliability standards for production environments through a rigorous test suite.*

- **License:** GPLv2 with Classpath Exception (GPLv2+CE).
- **Key advantages:** Enables Microsoft to accelerate delivery of important **security fixes and improvements** (backports) for its customers and internal users, which may not be immediately available in the original upstream release.
- **Integration:** It is the default distribution for managed Java services on **Microsoft Azure* and is used internally by Microsoft for over 500,000 Java Virtual Machines (JVMs).
