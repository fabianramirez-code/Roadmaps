# Style Conventions

Google Java Style, Oracle Code Conventions, names

A style convention makes code easier to read and review as a team; choose a guide for the project and apply it consistently. Comparison between the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) and [Oracle's Code Conventions for the Java Programming Language](https://www.oracle.com/java/technologies/javase/codeconventions-contents.html) (historical guide). **Documentary comparison pending (unverified):** the official pages cannot be accessed from this environment; the rules in the table and the naming rules are presented as guidance, not as a current verification of their contents.

| Aspect | Google Java Style | Oracle Code Conventions |
|---|---|---|
| Indentation | 2 spaces per level; continuations of at least 4. | 4 spaces per level; continuations of 8. |
| Line length | Limit of 100 characters, with exceptions (e.g., imports). | Avoid lines longer than 80 characters. |
| Braces | On the same line as the declaration or condition; required even for single-statement blocks. | On the same line; recommends using them even for a single statement. |
| Imports | One class per import, no `*`; separated into static and non-static groups, ordered within each group. | Declares imports after the package; that guide does not specify a detailed order or prohibit `*`. |
| Modifier order | Follows the order recommended by the [Java Language Specification](https://docs.oracle.com/javase/specs/jls/se25/html/jls-8.html#jls-8.1.1). | Does not prescribe a detailed order of its own in that guide; consult the specification. |

## Names

| Element | Shared practical convention | Avoid |
|---|---|---|
| Package | Lowercase, for example `com.example.reports` (reverse domain name). | `Com.Example.Reports` |
| Class | Descriptive noun in `UpperCamelCase`: `ReportService`. | `report_service` |
| Method | Verb in `lowerCamelCase`: `copyReports`. | `Copy_Reports` |
| Variable | Meaningful name in `lowerCamelCase`: `reports`. | `l` for a collection of reports |
| Constant | Uppercase with underscores: `MAX_ATTEMPTS` (not every `final` field is a constant). | `maxAttempts` for a constant |
| Generic type parameter | Short uppercase letter such as `T`, or a descriptive name ending in `T`, such as `ElementT`, according to the Google guide. | `datatype` |

Minimal example (the incorrect names above are **contrasts**, not identifiers you should copy):

```java
package com.example.reports;

import java.util.List;

public final class ReportService {
    private static final int MAX_ATTEMPTS = 3;

    public <T> List<T> copyReports(List<T> reports) {
        return List.copyOf(reports);
    }
}
```

Formatting can be automated with tools; it will be covered in section 11_7, “Static Analysis and Formatting”. Choosing names remains a design decision.
