# History of Java (Sun, Oracle, OpenJDK) — milestones from JDK 1.0 to today

**Long-Term Support (LTS)**

RELEASE with LTS: 8, 11, 17, 21, 25, 29

Java was created in 1991 by James Gosling and his team at SUN MICROSYSTEMS under the name **OAK**, initially to program embedded devices in smart home appliances.

It was renamed **JAVA** and released to the public in 1995 with the slogan **"Write once, run anywhere"**, thanks to the **Java Virtual Machine (JVM)**.

Sun Microsystems launched the OpenJDK project in 2006 under the GPL license. Oracle acquired Sun Microsystems in 2010 and introduced a six-month release cycle starting with Java 9 in 2017, along with commercial licensing models for the JDK.

## Licenses — practical summary
If you use any **OpenJDK** distribution (Temurin, Corretto, Zulu, Liberica, Microsoft Build, etc.) → there is only one license: GPLv2+CPE, free for everything.

If you use Oracle JDK → it depends on the version and date:
- JDK 25 → NFTC, free until Sep 2028.
- JDK 21 → already moved to OTN as of the October 2026 CPU; production requires a subscription.
- JDK 17 / 11 / 8 → OTN for some time now; production requires a subscription.

In practice, there are two worlds: the **OpenJDK** world (one license, GPL) and the **Oracle JDK** world (three licenses that follow each other over time: **NFTC → OTN → paid subscription).**

### Currently (November 2026), four active licenses plus one historical license exist:

| **License** | **Applies to**| **Free in production?**| **Key restriction** |
|---|---|---|---|
| **GPLv2 + CPE** | OpenJDK (and all its derivatives: Temurin, Corretto, Zulu, Microsoft Build, etc.) | **Yes**, forever | Only requires modifications to the JDK itself to be published under GPL |
| **NFTC** (No-Fee Terms & Conditions) | Oracle JDK 25 (until Sep 2028); applied to JDK 21 until Sep 2026 | **Yes**, but for a limited period | Stops applying 1 year after the next LTS; moves to OTN |
| **OTN** (Oracle Technology Network) | Oracle JDK 8 (≥8u211), 11, 17 (≥17.0.13), 21 (since Oct 2026) | **No** — personal use, development, testing, prototyping and demos only | Production use requires a paid subscription |
| **Java SE Universal Subscription** | Oracle JDK (any version under OTN) | The **paid** license | $15 → $5.25 per employee/month depending on tier; covers *all* company employees |
| ~~BCL~~ (Binary Code License) | Java 8 through 8u202 (2019) | Yes, but **obsolete** | No longer receives patches; of historical interest only |
