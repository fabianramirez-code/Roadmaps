# Convenciones de estilo

Google Java Style, Oracle Code Conventions, nombres

Una convención de estilo facilita leer y revisar código en equipo; elige una guía para el proyecto y aplícala de forma consistente. Comparación entre [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html) y [Code Conventions for the Java Programming Language de Oracle](https://www.oracle.com/java/technologies/javase/codeconventions-contents.html) (guía histórica). **Contraste documental pendiente (sin verificar):** no hay acceso a las páginas oficiales desde este entorno; las reglas de la tabla y de nombres se presentan como orientación, no como comprobación actual de su contenido.

| Aspecto | Google Java Style | Oracle Code Conventions |
|---|---|---|
| Sangría | 2 espacios por nivel; continuaciones de al menos 4. | 4 espacios por nivel; continuaciones de 8. |
| Longitud de línea | Límite de 100 caracteres, con excepciones (p. ej., importaciones). | Evitar líneas de más de 80 caracteres. |
| Llaves | En la misma línea que la declaración o condición; obligatorias incluso en bloques de una sola instrucción. | En la misma línea; recomienda usarlas incluso para una sola instrucción. |
| Imports | Una clase por importación, sin `*`; separados en grupos estáticos y no estáticos, ordenados dentro de cada grupo. | Declara importaciones tras el paquete; no fija en esa guía un orden detallado ni prohíbe `*`. |
| Orden de modificadores | Sigue el orden recomendado por la [especificación del lenguaje Java](https://docs.oracle.com/javase/specs/jls/se25/html/jls-8.html#jls-8.1.1). | No prescribe en esa guía un orden propio detallado; consulta la especificación. |

## Nombres

| Elemento | Convención práctica compartida | Evita |
|---|---|---|
| Paquete | Minúsculas, por ejemplo `com.ejemplo.informes` (dominio inverso). | `Com.Ejemplo.Informes` |
| Clase | Sustantivo descriptivo en `UpperCamelCase`: `InformeService`. | `informe_service` |
| Método | Verbo en `lowerCamelCase`: `copiarInformes`. | `Copiar_Informes` |
| Variable | Nombre significativo en `lowerCamelCase`: `informes`. | `l` para una colección de informes |
| Constante | Mayúsculas con guiones bajos: `MAX_INTENTOS` (no todo campo `final` es una constante). | `maxIntentos` para una constante |
| Parámetro de tipo genérico | Letra mayúscula breve como `T`, o nombre descriptivo con `T` final como `ElementoT` según la guía de Google. | `tipodato` |

Ejemplo mínimo (los nombres incorrectos anteriores son **contraste**, no identificadores que debas copiar):

```java
package com.ejemplo.informes;

import java.util.List;

public final class InformeService {
    private static final int MAX_INTENTOS = 3;

    public <T> List<T> copiarInformes(List<T> informes) {
        return List.copyOf(informes);
    }
}
```

El formato puede automatizarse con herramientas; se verá en la sección 11_7, «Análisis estático y formato». La elección de nombres sigue siendo una decisión de diseño.
