# IntelliJ IDEA, Eclipse, VS Code con Extension Pack for

# IntelliJ IDEA — proyectos, SDK por módulo, inspecciones, atajos

Un **entorno de desarrollo integrado** (IDE) reúne editor, compilación y navegación. En [IntelliJ IDEA](https://www.jetbrains.com/help/idea/discover-intellij-idea.html), un **proyecto** agrupa módulos; cada módulo puede tener su propio kit de desarrollo de Java (Java Development Kit, **JDK**) y nivel de lenguaje. El **Software Development Kit** (**SDK**) de Java en la interfaz apunta a una instalación del JDK, no al nivel de lenguaje ([configuración de SDK](https://www.jetbrains.com/help/idea/sdk.html), [módulos](https://www.jetbrains.com/help/idea/configure-modules.html)).

1. Abre **File > Project Structure** y en **Project > SDK** elige **Add SDK > JDK** y la carpeta raíz del JDK instalado (no `bin`); fija el **Language level** que corresponda al proyecto.
2. En **Modules > Dependencies > Module SDK**, selecciona **Project SDK** para heredarlo o un JDK diferente para ese módulo; revisa también **Sources > Language level** si el módulo necesita un nivel distinto. Configura por separado la versión de Java del sistema de construcción si el proyecto usa uno: cambiar el SDK del editor no sustituye su configuración.
3. Las [inspecciones](https://www.jetbrains.com/help/idea/code-inspection.html) marcan errores y sugerencias mientras editas: usa **Alt+Enter** sobre el aviso para ver la explicación o una corrección; ajusta su severidad en **Settings > Editor > Inspections**.

| Atajo (Windows; mapa predeterminado, sin verificar en esta máquina) | Uso |
|---|---|
| `Alt+Enter` | Acciones de contexto y correcciones. |
| `Ctrl+Shift+A` | Buscar acciones y ajustes. |
| `Ctrl+Alt+L` | Reformatear código. |
| `Shift+F10` | Ejecutar configuración actual. |
| `Shift+F9` | Depurar configuración actual. |

Consulta el [mapa oficial de teclas](https://www.jetbrains.com/help/idea/mastering-keyboard-shortcuts.html): los atajos pueden variar con el mapa elegido y los conflictos de Windows.

# Eclipse — workspace, perfiles de compilador

En [Eclipse IDE](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.user/concepts/concepts-12.htm), el **workspace** es el directorio que contiene preferencias y referencias a proyectos; un proyecto puede estar físicamente fuera de él. La configuración del compilador del workspace sirve de valor predeterminado; un proyecto puede sobrescribirla ([preferencias de Java](https://help.eclipse.org/latest/topic/org.eclipse.jdt.doc.user/tasks/task-choose_config_jre.htm)).

1. En **Window > Preferences > Java > Installed JREs**, añade **Standard VM** apuntando a la carpeta raíz del JDK y selecciónalo como predeterminado del workspace. **Java Runtime Environment** (**JRE**) es el nombre de esa pantalla, aunque selecciones un JDK completo.
2. Para un proyecto, abre **Properties > Java Build Path > Libraries** y selecciona el JDK mediante **JRE System Library**; revisa **Properties > Java Compiler** y activa la configuración específica del proyecto para fijar el nivel de compatibilidad. El nivel del compilador controla la sintaxis/bytecode; no instala ni cambia por sí solo el JDK usado por el proyecto. Véanse las [opciones del compilador](https://help.eclipse.org/latest/topic/org.eclipse.jdt.doc.user/reference/preferences/java/ref-preferences-compiler.htm).

| Atajo (Windows; mapa predeterminado, sin verificar en esta máquina) | Uso |
|---|---|
| `Ctrl+Shift+O` | Organizar imports. |
| `Ctrl+Shift+F` | Formatear código. |
| `Ctrl+1` | Corrección rápida. |
| `F3` | Ir a declaración. |
| `Ctrl+Space` | Completar código. |

Consulta los [atajos en Eclipse](https://help.eclipse.org/latest/topic/org.eclipse.platform.doc.user/concepts/accessibility/keyboardshortcuts.htm) o **Window > Preferences > General > Keys** para comprobar tu combinación activa.

# VS Code con Extension Pack for Java

[Visual Studio Code](https://code.visualstudio.com/docs/java/java-tutorial) (VS Code) necesita [Extension Pack for Java](https://marketplace.visualstudio.com/items?itemName=vscjava.vscode-java-pack) para reunir soporte del lenguaje, proyectos y depuración. Abre la **carpeta del proyecto**, no solo un `.java`, y espera a que termine la importación. En un proyecto con Maven o Gradle, el modelo de construcción también determina la versión de Java: no basta con cambiar el JDK que usa el editor ([gestión de proyectos Java](https://code.visualstudio.com/docs/java/java-project)).

1. Ejecuta **Java: Configure Java Runtime** desde la paleta de comandos: comprueba el JDK predeterminado y asigna al proyecto uno de los JDK detectados. Si falta, configúralo en `java.configuration.runtimes` con la ruta a su carpeta raíz; los proyectos Maven/Gradle requieren además ajustar su propia configuración de Java.
2. Usa el panel **JAVA PROJECTS** para inspeccionar el proyecto y sus bibliotecas; las sugerencias y errores aparecen en el editor y en **Problems**. Consulta la [configuración de entornos Java](https://code.visualstudio.com/docs/java/java-project#_configure-runtime-for-projects).

| Atajo (Windows; mapa predeterminado, sin verificar en esta máquina) | Uso |
|---|---|
| `Ctrl+Shift+P` | Abrir paleta de comandos. |
| `Ctrl+Space` | Sugerencias de código. |
| `Ctrl+.` | Acciones rápidas. |
| `F12` | Ir a definición. |
| `F5` | Iniciar depuración. |

El [editor de atajos](https://code.visualstudio.com/docs/getstarted/keybindings) permite comprobar o cambiar las teclas de cada acción.

**Elección rápida:** IntelliJ IDEA si priorizas navegación e inspecciones integradas; Eclipse si trabajas con proyectos y preferencias de un workspace; VS Code si prefieres un editor ligero extensible. En los tres, confirma que el JDK del proyecto coincida con el exigido por su construcción.

Para comprobar en PowerShell que el ejecutable de Java procede del mismo JDK que el compilador (aunque otro `java` aparezca antes en la variable `PATH`):

```bash
$javac = (Get-Command javac.exe).Source # Localiza el compilador activo
& $javac -version # Muestra su versión
& (Join-Path (Split-Path $javac) 'java.exe') -version # Usa el lanzador del mismo JDK
```
