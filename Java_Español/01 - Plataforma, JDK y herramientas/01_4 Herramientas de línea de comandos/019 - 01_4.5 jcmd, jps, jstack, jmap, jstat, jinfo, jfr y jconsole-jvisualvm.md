# jcmd, jps, jstack, jmap, jstat, jinfo, jfr y jconsole-jvisualvm

# jcmd — comando de diagnóstico universal de la JVM

La Java Virtual Machine (JVM), o máquina virtual de Java, ejecuta el programa. [`jcmd`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jcmd.html) permite consultar y diagnosticar una JVM local; ejecuta las herramientas con el mismo usuario que inició el proceso. Algunas operaciones, como el volcado de memoria, consumen tiempo y espacio: úsalas con cuidado.

Para probar **todos** los comandos de esta nota, crea `Espera.java` dentro de `Ejemplos_019` (sin crear archivos desde la nota). El hilo llamado `trabajador` permanece en espera; conserva abierta la primera terminal mientras inspeccionas el proceso desde otra:

```java
import java.util.concurrent.TimeUnit;

public class Espera {
    public static void main(String[] args) throws InterruptedException {
        Thread trabajador = new Thread(() -> {
            while (!Thread.currentThread().isInterrupted()) {
                try {
                    TimeUnit.SECONDS.sleep(1);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }, "trabajador");
        trabajador.start();
        trabajador.join();
    }
}
```

```bash
javac Espera.java
java Espera                           # Primera terminal: detén el proceso con Ctrl+C al terminar
```

En la segunda terminal, situada también en `Ejemplos_019`, identifica el process identifier (PID), número que distingue al proceso; **sustituye** `<pid>` por ese número en los comandos siguientes. La sintaxis es `jcmd <pid> <comando>`; sin argumentos, enumera los mismos procesos Java que la opción de listado. `help` consulta los comandos disponibles **en esa JVM**.

El volcado del montón y el inicio de una grabación de Java Flight Recorder (JFR), el registrador de eventos de la JVM, pueden provocar pausas o sobrecarga de rendimiento, además de consumir tiempo y espacio. El volcado puede contener datos sensibles; también pueden contenerlos las propiedades del sistema y las grabaciones: revísalos antes de compartirlos.

```bash
jcmd -l                                               # Lista procesos Java (igual que sin argumentos)
jcmd <pid> help                                       # Comandos admitidos por esta JVM
jcmd <pid> VM.version                                 # Versión
jcmd <pid> VM.flags                                   # Opciones de arranque y configuración
jcmd <pid> VM.system_properties                       # Propiedades del sistema
jcmd <pid> VM.uptime                                  # Tiempo en ejecución
jcmd <pid> Thread.print                               # Estado y trazas de hilos; examina bloqueos
jcmd <pid> GC.heap_info                               # Resumen de memoria
jcmd <pid> GC.run                                     # Solicita recolección de basura (Garbage Collection, GC)
jcmd <pid> GC.heap_dump heap.hprof                    # Volcado del montón a un archivo potencialmente grande
jcmd <pid> JFR.start name=estudio                     # Inicia la grabación
jcmd <pid> JFR.dump name=estudio filename=registro.jfr # Guarda la grabación
jcmd <pid> JFR.stop name=estudio                      # Detiene la grabación
```

# jps, jstack, jmap, jstat, jinfo — diagnóstico básico

Estas herramientas del Java Development Kit (JDK), kit de desarrollo de Java, ofrecen consultas específicas; [`jcmd`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jcmd.html) cubre casi todas y suele ser la primera opción. Consulta los manuales de [`jps`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jps.html), [`jstack`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jstack.html), [`jmap`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jmap.html), [`jstat`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jstat.html) y [`jinfo`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jinfo.html).

Las consultas de histograma y volcado con `jmap` también pueden provocar pausas o sobrecarga; aplica las precauciones de tiempo, espacio y datos sensibles indicadas arriba.

```bash
jps -l                                         # Identificadores y nombres completos de clases o archivos Java Archive (JAR, archivo de clases empaquetadas)
jps -v                                         # Argumentos de la JVM
jstack <pid>                                  # Estado y trazas de hilos; indica interbloqueos (deadlocks) al final
jmap -histo <pid>                              # Histograma de objetos
jmap -dump:format=b,file=heap.hprof <pid>      # Volcado binario; cambia el nombre si ya existe el archivo
jstat -gc <pid> 1s 2                          # Dos muestras, separadas un segundo: capacidades y actividad de GC
jstat -gcutil <pid> 1s 2                      # Dos muestras, separadas un segundo: ocupación en porcentajes
jinfo -flags <pid>                            # Opciones de la JVM
jinfo -sysprops <pid>                         # Propiedades del sistema (pueden contener datos sensibles)
```

# jfr y jconsole/jvisualvm (este último ya no está en el JDK)

[`jfr`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jfr.html) **lee** el archivo `registro.jfr` creado antes; revisa los datos sensibles de la grabación antes de compartirla. [`jconsole`](https://docs.oracle.com/en/java/javase/25/docs/specs/man/jconsole.html) sigue incluido en el JDK y ofrece monitorización gráfica: ejecútalo y selecciona el proceso `Espera`. [VisualVM](https://visualvm.github.io/) es un proyecto independiente: `jvisualvm` dejó de distribuirse con el JDK desde Java 9; hay que instalarlo por separado.

```bash
jfr summary registro.jfr                             # Resumen y cantidad de eventos, en la linea #50 se creo el archivo
jfr view all-events registro.jfr                     # Tabla de eventos (puede ser extensa)
jfr print --events jdk.JVMInformation registro.jfr   # Eventos de información de la JVM, si los hay
jconsole                                             # Abre la interfaz gráfica para conectar al proceso local
```

# Comandos para Linux/macOS

Los comandos de consola anteriores no cambian; en sistemas sin escritorio gráfico no se puede abrir `jconsole`. El diagnóstico local también puede estar restringido por permisos del sistema.
