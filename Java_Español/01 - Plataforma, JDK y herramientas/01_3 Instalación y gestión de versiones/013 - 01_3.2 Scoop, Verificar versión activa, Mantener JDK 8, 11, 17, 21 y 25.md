# Scoop, Verificar versión activa, Mantener JDK 8, 11, 17, 21 y 25

# Scoop (https://scoop.sh/)
Gestor de paquetes para Windows que instala en tu carpeta de usuario (`~\scoop`), sin administrador.  

> Los JDK viven en el bucket **`java`**: https://github.com/ScoopInstaller/Java

```bash
# Instalar Scoop
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

# Añadir el bucket de Java
scoop bucket add java

# Buscar e instalar
scoop search temurin
scoop install temurin21-jdk
scoop install corretto21-jdk     # otras distribuciones: zulu21-jdk, oraclejdk, openjdk, etc.

# Mantenimiento
scoop list                       # instalados
scoop update                     # actualiza Scoop y buckets
scoop update temurin21-jdk       # actualiza un paquete
scoop uninstall temurin21-jdk
```

- Scoop deja cada JDK en `~\scoop\apps\<paquete>\current` y gestiona `JAVA_HOME` y `PATH` del usuario por ti.
- Los nombres exactos de paquete cambian con el tiempo: confírmalos con `scoop search`.

## Verificar versión activa

```bash
java -version        # funciona en todas las versiones (imprime en stderr)
javac -version       # compilador: confirma que es un JDK y no solo un JRE
java --version       # solo Java 9+; en Java 8 falla con "Unrecognized option"

echo $env:JAVA_HOME  # qué JDK cree usar tu entorno
where.exe java       # todos los java en el PATH; el primero es el que se ejecuta
```

> Si `java -version` y `JAVA_HOME` no coinciden, manda el **primer `java` del `PATH`**, no `JAVA_HOME`. Muchas herramientas (Maven, Gradle, IDEs), en cambio, leen `JAVA_HOME`: por eso ambos deben apuntar al mismo JDK.

## Mantener JDK 8, 11, 17, 21 y 25 en paralelo

Útil para reproducir código legado y probar compatibilidad entre versiones LTS.

```bash
# Instalar las cinco LTS
scoop install temurin8-jdk temurin11-jdk temurin17-jdk temurin21-jdk temurin25-jdk

# Cambiar la versión activa (reasigna `current`, JAVA_HOME y PATH)
scoop reset temurin8-jdk
java -version                    # 1.8.0_xxx

scoop reset temurin21-jdk
java -version                    # 21.x
```

Usar una versión **solo en esta terminal**, sin tocar la configuración global:

```bash
$env:JAVA_HOME = "$env:USERPROFILE\scoop\apps\temurin17-jdk\current"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
java -version
```

Convenciones útiles:

- Deja como **default** la LTS que uses a diario (hoy 21 o 25) y cambia a la antigua solo cuando reproduzcas un bug.
- Cada proyecto fija su versión en la build (`maven.compiler.release`, Gradle toolchains), no en el entorno.
- Java 8 reporta su versión como `1.8.0_xxx`; desde Java 9 es `9`, `11`, `17`…
- Alternativas equivalentes: SDKMAN (`sdk use java …`) o Jabba, vistas en la nota anterior.
